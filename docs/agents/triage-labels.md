# Triage labels

| Role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation needed |
| `needs-info` | Waiting for reporter information |
| `ready-for-agent` | Fully specified and available for unattended implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be implemented |
